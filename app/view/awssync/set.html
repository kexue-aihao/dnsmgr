功能简介

本功能用于在 AWS 小助理 更换 EC2 公网 IP 之后，由彩虹 DNS 自动读取实例当前 IP，并更新到指定子域名的 A 记录。

彩虹 DNS 不会主动触发换 IP，只负责同步解析。换 IP 请在小助理面板操作。

凭证说明

登录 aws.sb 后，浏览器地址栏形如：

https://aws.sb/#/?token=xxxx

其中 token= 后面的字符串即为 X-Auth-Token。

保存 Token 后，可在下方自动读取小助理上的账号与 EC2 实例，添加同步任务时直接下拉选择，无需手填 ID。
