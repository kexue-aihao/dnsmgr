操作步骤：
  1. 先到 API 设置 保存小助理 Token（aws.sb 地址栏 token= 后面的内容）
  2. 点击绿色 添加 按钮进入添加页
  3. 选择域名 → 点 读取解析记录 → 在下拉框选一条 A 记录
  4. 读取 AWS 账号 → 选账号 → 读取实例 → 选 EC2 实例 → 设置间隔 → 保存
